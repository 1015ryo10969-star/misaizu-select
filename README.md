# misaizu-select
美斉津商店WEBの第2ポータルサイト。推し活・AI・noteなどのおすすめコンテンツをセレクトして紹介するブランドショーケースです。AIが制作・更新を担当し、人間が編集・監修する運用を前提としています。

## FEATUREDの掲載スケジュール

`data/featured.json` で掲載開始日・終了日をJST基準で設定できます。期間内の特集を優先し、該当する特集がない日は日付未設定の候補から1件を日替わり表示します。同じ日・同じ設定ならリロードしても同じ記事になります。

設定方法は [記事表示スケジュール](記事表示スケジュール.md) を参照してください。通常の記事一覧や独自ドメイン設定は変更していません。
